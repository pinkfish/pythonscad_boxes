    Brink (brink)¶

    Brink board game organizer.

    • Source Script: boxes/brink/brink.py

    • Game Box Dimensions: 215 × 307 × 96 mm (usable height 78 mm with 18 mm board storage)

    • Boxes: 20 sub-box(es), 2 spacer tray(s)

    • Box Types Used: BoxType.CAP, BoxType.SLIDING, BoxType.NO_LID
