    Board-Game Insert Gallery¶

    Complete gallery of all board-game insert projects included in boxes/. Each page provides interactive 3-D STL viewers and downloadable STL meshes for:

    • Full Box Packing — all sub-boxes, lids, and spacer trays positioned inside the game box,

    • Each Box Individually — assembled view of each box with its lid, and

    • All Individual Parts — separate printable body, lid, and spacer STL meshes, with cross-reference links to each Box Types Guide & Gallery mechanism.
