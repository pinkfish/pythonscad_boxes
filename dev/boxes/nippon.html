    Nippon (nippon)¶

    Nippon board game organizer.

    • Source Script: boxes/nippon/nippon.py

    • Game Box Dimensions: 303 × 380 × 70 mm (usable height 37.8 mm with 32.2 mm board storage)

    • Boxes: 11 sub-box(es), 3 spacer tray(s)

    • Box Types Used: BoxType.CAP, BoxType.SLIDING, BoxType.NO_LID
