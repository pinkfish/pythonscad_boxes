    pyboxbuilder.lid.color_layers¶

    Accent colours for multi-material lids (FR-022).

    Three colours are settable independently — the label text, the frame’s top layer and the pattern’s top layer — and each has a default derived from the body colour rather than left unset. That matters: an unset accent is not a subtle default, it is no colour, so the feature only worked for a caller who already knew to set all three (FR-000a).
