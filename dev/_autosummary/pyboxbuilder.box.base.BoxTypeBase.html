    pyboxbuilder.box.base.BoxTypeBase¶

    class pyboxbuilder.box.base.BoxTypeBase[source]¶

    Bases: object

    Base for every box type implementation.

    A subclass must provide build_body(), and build_lid() unless it is a lidless type. Everything else has a default that suits a plain box with a lid sitting on top of it.

    cut_fingernail_catch(lid: Bosl2Solid, spec: BoxSpec) → Bosl2Solid[source]¶

    Sink the dish a nail starts a sliding lid with (FR-002e5).

    A seated sliding lid is a plate flush with the box’s top: its only exposed surfaces are an end face one lid thickness tall and a smooth top, so there is nothing to grip. The dish is what gets it moving. A lid that lifts off has its own way open and takes no dish.

    Parameters:¶
    lid: Bosl2Solid¶

    The lid to cut.

    spec: BoxSpec¶

    The box’s resolved description.

    Returns:¶

    The lid, dished — or unchanged for a non-sliding type, a box that declines a catch, or a lid too small to carry one.

    The interior frame. The default is the spec’s own — walls on four sides, floor below, lid above — which types that shorten the body for their lid override.

    interior_mask(spec: BoxSpec) → Bosl2Solid | None[source]¶

    Return the volume inside the box that contents may actually occupy.

    Usually the whole interior, and a type only says otherwise when something of its own stands in there. A hinge box is the case that needs it: keeping the hinge inside the box’s outline puts the barrel and its leaf webs in the back of the interior, exactly where a compartment would go (FR-002s).

    Parameters:¶
    spec: BoxSpec¶

    The box’s resolved description.

    Returns:¶

    A solid the contents must stay within, or None when the whole interior is available.

    lid_keepouts(spec: BoxSpec) → list[tuple[float, float, float]][source]¶

    Return circles on the lid that decoration must leave solid.

    A type declares these when its lid carries a feature of its own that a pattern would otherwise cut into — a sliding lid’s fingernail dish is the case (FR-002e5): it is a thinned spot that gets pulled on, so it needs whole material around it to pull against.

    Parameters:¶
    spec: BoxSpec¶

    The box’s resolved description.

    Returns:¶

    (x, y, radius) in the lid’s own frame; empty when the type’s lid is a plain plate.

    lid_rounded_edges(spec: BoxSpec) → list[Anchor][source]¶

    Which of this box type’s lid edges may be rounded.

    Parameters:¶
    spec: BoxSpec¶

    The box’s resolved description.

    Returns:¶

    A pybosl2 edges= selector. The default — four vertical corners and the top face — suits a lid that sits on top of the box, where all of that is on the outside. A lid that slides into the box overrides it (FR-044i).

    preferred_scoop_side(spec: BoxSpec) → ScoopSide | None[source]¶

    Which wall this box type wants a finger scoop in.

    A hook rather than a rule, because only the type knows: on a sliding box the cut has to be in the wall the lid leaves by — the other three carry the lid, two of them holding the grooves it rides in (FR-069).

    Parameters:¶
    spec: BoxSpec¶

    The box’s resolved description.

    Returns:¶

    A ScoopSide, or None for “no preference”, which leaves the compartment’s own shape to decide.

    slide_axis(spec: BoxSpec) → str | None[source]¶

    Return which axis this type’s lid slides along, if it slides at all.

    Parameters:¶
    spec: BoxSpec¶

    The box’s resolved description.

    Returns:¶

    "x" or "y", or None for a lid that lifts off rather than sliding. Everything that follows from sliding — the fingernail catch below — asks this rather than each type answering it again.
