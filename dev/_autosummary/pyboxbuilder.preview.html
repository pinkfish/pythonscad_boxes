    pyboxbuilder.preview¶

    View-time helpers for pyboxbuilder.Project.show().

    Nothing in this module affects exported geometry. Colours assigned here are a preview aid so a viewer can tell one box from another; the material a box prints in is decided by the exporter, not by this file.

    class pyboxbuilder.preview.PreviewPiece(label: str, solid: Bosl2Solid, color: Color, kind: str)[source]¶

    Bases: object

    One solid in a preview, with the colour it should be drawn in.

    Each box, lid and spacer is a separate piece — the preview never unions them, since a union collapses these colours into one.

    color : Color¶

    The colour to draw this piece in.

    kind : str¶

    One of "body", "lid" or "spacer".

    label : str¶

    The piece’s box label; lids and spacers keep their box’s label.

    solid : Bosl2Solid¶

    The built geometry, already translated to its packed position.

    pyboxbuilder.preview.lid_color(box_color: Color) → Color[source]¶

    Return the preview colour for a lid sitting on a box of box_color.

    A lid is drawn in a lighter shade at 50% alpha so it reads as a separate piece and the box underneath remains visible through it.

    Parameters:¶
    box_color: Color¶

    The colour of the box the lid belongs to.

    Returns:¶

    A lighter, semi-transparent pybosl2.Color.

    pyboxbuilder.preview.remove_top_layers(placements: collections.abc.Sequence[Piece], count: int) → list[Piece][source]¶

    Drop the top count vertical layers from a set of placements.

    A box is removed when its top surface rises above the cut, so a tall box spanning into a removed layer goes with it rather than being sliced.

    Parameters:¶
    placements: collections.abc.Sequence[Piece]¶

    Objects carrying position and size 3-tuples.

    count: int¶

    How many layers to remove from the top. 0 keeps everything; a count at or above the number of layers removes everything.

    Returns:¶

    The surviving placements, in their original order.

    Raises:¶

    ValueError – If count is negative.

    pyboxbuilder.preview.stable_color(label: str) → Color[source]¶

    Assign a distinct, stable preview colour to a box label.

    The same label always produces the same colour, across runs and processes, so a preview does not reshuffle its palette between renders.

    Parameters:¶

    The box label to derive a colour from.

    Returns:¶

    A saturated pybosl2.Color whose hue is derived from the label.
