pyboxbuilder
============

Board game box and insert design library for PythonSCAD.

``pyboxbuilder`` turns a declarative ``Project`` — game box size, wall/floor
thickness, and a list of boxes and their compartments — into the CSG geometry
that PythonSCAD renders and the 3MF files a slicer prints. It builds on
``pybosl2`` for every solid and shape.
