# Irish Gauge Board Game Organizer Specification

This document details the layout, component inventory, sub-box specifications, and 3D packing configuration for the **Irish Gauge** board game organizer, ported from `examples/irish_gauge.scad` to PythonSCAD (`pyboxbuilder`).

---

## 1. Game Box Dimensions & Constraints

* **Game Box Footprint**: `214.0mm (Width) x 302.0mm (Length) x 39.0mm (Height)`
* **Board Thickness**: `10.5mm` (Game board sits on top of the sub-boxes at `Z = 28.5 .. 39.0mm`)
* **Main Insert Usable Height**: `28.5mm` (`Z = 0.0 .. 28.5mm`)
* **Wall Thickness**: `3.0mm`
* **Lid Thickness**: `3.0mm`
* **Clearance Slack**: `0.0mm`

## 3. Sub-Box Specifications

### 3.1 Bank Currency Box (`MoneyBox`)
* **Dimensions**: `214.0mm (Width) x 77.0mm (Length) x 28.5mm (Height)`.
* **Arrangement**: Sits across the full front width of the game box at `X = 0.0mm`, `Y = 0.0mm`, `Z = 0.0mm`.
* **Lid Mechanism**: `BoxType.FILAMENT_HINGE` with framed "Bank" label.
* **Compartments**: 3 equal-width card wells (`49.0 x 67.0 x 28.5mm`) labeled "1", "5", and "10" with curved side finger scoops (`FingerCut.SCOOP`).

### 3.2 Company Boxes (`CompanyBox0` .. `CompanyBox4`)
* **Dimensions**: `53.5mm x 133.8mm x 14.25mm` (each box is half the usable height).
* **Arrangement**:
  * Lower tier (`Z = 0.0mm`): `CompanyBox0` (Belfast), `CompanyBox1` (Cork), `CompanyBox2` (Midland) arranged at `Y = 77.0mm`, `X = 0.0mm, 53.5mm, 107.0mm`.
  * Upper tier (`Z = 14.25mm`): `CompanyBox3` (Waterford) and `CompanyBox4` (Great Southern) stacked above `CompanyBox0` and `CompanyBox1`.
* **Lid Mechanism**: `BoxType.SLIDING`.
* **Compartments**:
  * **Share Cards**: Sized to fit 49.0 x 71.0mm cards stacked to the company's share count (`depth = shares * 0.7mm + 1.0mm`) with a through-floor push hole.
  * **Train Miniatures**: Holds 19 wooden trains (`7.75 x 5.5 x 8.0mm`) in a 6x4 array (`33.0 x 31.0 x 8.0mm`) with a through-floor finger cut.
  * **Dividend Marker**: Precision cylindrical pocket (`7.5mm` dia x `3.0mm` depth).

### 3.3 Automatic Derived Spacers
* Residual volumes behind the company boxes (`Y = 210.8 .. 302.0mm`) and above the third company column (`X = 107.0 .. 214.0mm`, `Z = 14.25 .. 28.5mm`) are automatically generated by the `pyboxbuilder` spacer solver.
