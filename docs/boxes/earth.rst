.. _box-insert-earth:

Earth (earth)
=============

Earth (+ Abundance expansion) board game organizer.

- **Source Script**: ``boxes/earth/earth.py``
- **Game Box Dimensions**: ``288 × 288 × 72 mm`` (usable height ``55.2 mm`` with ``16.8 mm`` board storage)
- **Boxes**: 26 sub-box(es), 1 spacer tray(s)
- **Box Types Used**: :ref:`BoxType.SLIDING <box-type-sliding>`, :ref:`BoxType.FILAMENT_HINGE <box-type-filament-hinge>`, :ref:`BoxType.SLIPOVER <box-type-slipover>`, :ref:`BoxType.NO_LID <box-type-no-lid>`, :ref:`BoxType.CAP <box-type-cap>`
