PioneerRails (pioneer_rails)
============================

Pioneer Rails board game organizer.

- **Source Script**: ``boxes/pioneer_rails/pioneer_rails.py``
- **Game Box Dimensions**: ``209 × 209 × 38 mm`` (usable height ``22 mm`` with ``16 mm`` board storage)
- **Boxes**: 5 sub-box(es), 1 spacer tray(s)
- **Box Types Used**: :ref:`BoxType.CAP <box-type-cap>`, :ref:`BoxType.SLIDING <box-type-sliding>`, :ref:`BoxType.NO_LID <box-type-no-lid>`
