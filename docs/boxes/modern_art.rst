ModernArt (modern_art)
======================

Modern Art board game organizer.

- **Source Script**: ``boxes/modern_art/modern_art.py``
- **Game Box Dimensions**: ``154 × 208 × 44 mm`` (usable height ``38 mm`` with ``6 mm`` board storage)
- **Boxes**: 2 sub-box(es)
- **Box Types Used**: :ref:`BoxType.CAP <box-type-cap>`
