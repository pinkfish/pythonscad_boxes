KenmoreGold (kenmore_gold)
==========================

Kenmore Gold board game organizer.

- **Source Script**: ``boxes/kenmore_gold/kenmore_gold.py``
- **Game Box Dimensions**: ``130 × 120 × 77 mm``
- **Boxes**: 3 sub-box(es), 2 spacer tray(s)
- **Box Types Used**: :ref:`BoxType.CAP <box-type-cap>`, :ref:`BoxType.NO_LID <box-type-no-lid>`
