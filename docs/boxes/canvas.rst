.. _box-insert-canvas:

Canvas (canvas)
===============

Canvas board game organizer.

- **Source Script**: ``boxes/canvas/canvas.py``
- **Game Box Dimensions**: ``200 × 250 × 50 mm``
- **Boxes**: 7 sub-box(es)
- **Box Types Used**: :ref:`BoxType.NO_LID <box-type-no-lid>`, :ref:`BoxType.CAP <box-type-cap>`
