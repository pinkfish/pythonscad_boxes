Cascadero (cascadero)
=====================

Cascadero board game organizer.

- **Source Script**: ``boxes/cascadero/cascadero.py``
- **Game Box Dimensions**: ``212 × 304 × 40 mm`` (usable height ``26 mm`` with ``14 mm`` board storage)
- **Boxes**: 7 sub-box(es)
- **Box Types Used**: :ref:`BoxType.SLIDING <box-type-sliding>`
