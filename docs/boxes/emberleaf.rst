Emberleaf (emberleaf)
=====================

Emberleaf board game organizer.

- **Source Script**: ``boxes/emberleaf/emberleaf.py``
- **Game Box Dimensions**: ``287 × 287 × 79 mm`` (usable height ``52.5 mm`` with ``26.5 mm`` board storage)
- **Boxes**: 18 sub-box(es), 3 spacer tray(s)
- **Box Types Used**: :ref:`BoxType.CAP <box-type-cap>`, :ref:`BoxType.SLIDING <box-type-sliding>`, :ref:`BoxType.NO_LID <box-type-no-lid>`
