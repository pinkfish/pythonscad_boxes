18Cuba (18_cuba)
================

18Cuba board game organizer.

- **Source Script**: ``boxes/18_cuba/18_cuba.py``
- **Game Box Dimensions**: ``225 × 314 × 68 mm`` (usable height ``42 mm`` with ``26 mm`` board storage)
- **Boxes**: 5 sub-box(es), 2 spacer tray(s)
- **Box Types Used**: :ref:`BoxType.SLIPOVER <box-type-slipover>`, :ref:`BoxType.NO_LID <box-type-no-lid>`
