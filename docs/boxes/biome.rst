.. _box-insert-biome:

Biome (biome)
=============

Biome board game organizer.

- **Source Script**: ``boxes/biome/biome.py``
- **Game Box Dimensions**: ``285 × 285 × 73 mm`` (usable height ``53 mm`` with ``20 mm`` board storage)
- **Boxes**: 23 sub-box(es), 2 spacer tray(s)
- **Box Types Used**: :ref:`BoxType.CAP <box-type-cap>`, :ref:`BoxType.SLIDING <box-type-sliding>`, :ref:`BoxType.NO_LID <box-type-no-lid>`, :ref:`BoxType.SLIPOVER <box-type-slipover>`
